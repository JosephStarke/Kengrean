# Product Context

## Problem

Word-list quizzes alone get boring and don't build real understanding. Learners progress
fastest on comprehensible input — Korean they can follow from context and pictures.

## Solution

- Stories with recurring characters (Minji, Alex, Junho, Jian, Grandma, Nabi the cat) drawn
  in one consistent picture-book style, so the image carries the meaning.
- Each character has their own neural voice; slow mode and replay on every line.
- English subtitles blurred until tapped; highlighted words show meaning on tap.
- Varied practice (quiz modes + arcade games) to keep sessions fresh.

## User Flow

Learn path → unit → watch story → words → patterns → practice (stars) → next unit.
Practice and Words tabs let learners drill anything, anytime.
