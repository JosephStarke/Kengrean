# Project Brief: Kengrean

A static web app that teaches Korean from A0 to A2 through comprehensible input:
illustrated stories that play like short videos, natural neural-voice audio, and many
practice modes so learning stays fun.

## Core Requirements

- Course organised by CEFR-style levels: A0 (Hangul & first words), A1 (survival), A2 (everyday).
- Every non-Hangul unit: story (pictures + voiced lines + subtitles + comprehension checks),
  words, grammar patterns, and a starred practice quiz.
- Practice modes usable both inside a unit and on their own (any unit, level or word pack).
- Spaced-repetition review, XP, daily goal and streak saved in the browser.
- No build step and no frameworks; works on phones and desktops.
